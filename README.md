# vishchalla.github.io

Source for my personal site: <https://vishchalla.github.io>

Plain HTML, CSS and a small amount of JavaScript. No build step and no frameworks, so it loads fast and there is nothing to maintain.

```
index.html      all content
css/style.css   design tokens, layout, light and dark themes
js/main.js      theme toggle, scroll reveals, number count-up
assets/img/     charts generated by the project repositories
```

## Preview locally

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Updating

- Project charts are copied from each project's `docs/` folder. Regenerate them there and copy the PNGs into `assets/img/`.
- Every number on the page should match the README of the project it links to.
